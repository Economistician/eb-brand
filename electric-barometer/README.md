# Electric Barometer · Brand Assets

Canonical visual identity assets for Electric Barometer.

---

## Overview

This directory contains the official Electric Barometer brand assets used across documentation, websites, repositories, and presentation materials. It serves as the authoritative source for logos, icons, favicons, and related visual artifacts.

The contents of this directory are **static assets only**. No executable code, UI components, or styling logic are defined here.

---

## Contents

- **`favicon/`**
  Favicon assets, including SVG and multi-size ICO variants.

- **`logo/`**
  Primary Electric Barometer logos, including square variants for icon and avatar usage.

- **`icons/`**
  Supporting iconography derived from the core brand identity.

- **`tokens/`**
  Canonical color and styling tokens.

- **`scripts/`**
  Supporting utilities for asset generation and maintenance.

---

## Usage

Assets in this directory are intended to be referenced or consumed by downstream repositories and surfaces. They should be treated as authoritative to avoid duplication or visual drift.
